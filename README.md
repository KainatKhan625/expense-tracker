# Expense Tracker App 💰

A Flutter mobile app to track daily income and expenses.

## Features
- ✅ Add income and expense transactions
- ✅ Categories (Food, Transport, Bills, Shopping, Health, Education)
- ✅ Total balance, income, and expense summary
- ✅ Transaction history with date
- ✅ Delete transactions
- ✅ Local data storage with Hive

## Tech Stack
- Flutter
- Hive (local database)
- Provider (state management)
